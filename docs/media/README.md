# Project film

The approved 65-second **Room as Code — Edit with your voice** film is included as [`room-as-code.mp4`](room-as-code.mp4). [`../index.html`](../index.html) provides native browser playback, a download link and the English transcript. On GitHub, use the MP4 file link or the linked GIF in the repository README.

## Files

- `room-as-code.mp4`: web-encoded H.264/AAC copy of the approved final edit, 1600 × 900, 24 fps, 65 seconds, 48 kHz stereo. The shot order, captions and soundtrack are retained. Container metadata is stripped.
- `film-poster.jpg`: an actual frame of the corrected island model from the film.
- `build-a-room.gif`: a short, silent assembly excerpt from the opening, resized for the repository front page.
- `provenance.json`: source and published-file checksums and measured media properties.

The film combines native 3D preview capture and Blender renders with supplied reference photographs and labeled AI visualization generated with Atlas / Seedance 2.0 Mini. Voiceover is synthesized with xAI TTS. Music, atmosphere and transition effects were composed synthetically for the film. The two scene edits are real model transactions. Example voice narration is paired with assistant-driven editing; it is not a recording of built-in live speech recognition or a response-time benchmark.

Custom authored scene details in the film, including the corrected sink assembly, are showcase work; they are not a claim that every custom asset is included in the default parametric kit. Separate source-photo files, the editable production workspace, API credentials and provider request logs are not added to this repository.
